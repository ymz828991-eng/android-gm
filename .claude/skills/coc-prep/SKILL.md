# coc-prep 备团管线

把一份模组 PDF 加工成消费者（coc-consumer）可用的素材库。四步管线，**每步末尾停下等 KP 校对**。
本 skill 只产**模组库**（静态素材，跨团复用）；`runs/` 目录在开团时由 coc-pc-import / 生产者创建，同一模组可多次开团。

## 开始前

1. 确定 `campaign/<模组id>/`——模组 id 用英文小写下划线（如 `不息的渴望`），向 KP 确认
2. 提取模组全文（本机 Read 工具无法渲染 PDF，用已验证的 fitz 配方）：

```bash
python -c "
import fitz, sys
doc = fitz.open('<模组PDF路径>')
with open('logs/extracted/_<模组id>_mod.txt', 'w', encoding='utf-8') as f:
    for i, page in enumerate(doc):
        f.write(f'\n===== 第{i+1}页 =====\n' + page.get_text())
print(len(doc), '页')
"
```

然后通读全文（长模组分段读，每次不超过 40 页）。

## 四步管线

### 步骤 1：场景切分

- 按模组的场景边界（标题、地点转换、"读出"段落间隔）把全文切分为场景列表
- 每个场景产出骨架文件 `campaign/<模组id>/scenes/<中文名>.md`（如 `磨坊.md`、`进城之路.md`，与卡片标题同名；卡片间交叉引用一律用此名）
- **box text 识别规则**：模组中标注"读出/朗读/box/玩家用"的段落，或成段的环境描写成品文字，整段摘录进场景卡的 `box_texts` 节——这些**只可原文引用，不得改写**
- 线性模组在卡内"出入口"字段写 order 链；箱庭模组写场景网（多出口指向）

**停下，请 KP 校对：直接修改生成文件后说"继续"。**

### 步骤 2：场景卡 + NPC 卡生成

每个场景写完整场景卡（骨架之上补全）：

```markdown
# <场景名>（<id>）
## 浓缩摘要（≤150字，供上下文预算紧张时降级使用）
## 场景原文（完整保留，作家直接读原文）
## box_texts（只可原文引用的成品文本，注明使用时机）
## 出入口（进入条件 + 出口指向）
## 在场 NPC（引用 npcs/<id>）
## PC 挂注（coc-pc-import 写入，初始为空）
```

每个有声线的 NPC 写 `campaign/<模组id>/npcs/<中文名>.md`（与 NPC 名同名）：

```markdown
# <NPC 名>
## 声线卡
- 外貌：
- 特质：
- 扮演秘诀：（口头禅、小动作、语气）
- 动机：
## 知情边界（此人知道什么/不知道什么/会谎称什么）
## stats_ref: <数值表位置引用，数值不进上下文>
```

**停下，请 KP 校对：直接修改生成文件后说"继续"。**

### 步骤 3：真相摘要 + 理想路线

`campaign/<模组id>/module.md`：

```markdown
# <模组名>（<模组id>）
## 元信息（作者/年代/人数/时长/线性或箱庭）
## 真相摘要（≤500字，作家全知视角的底座）
## 伏笔登记表
| 编号 | 伏笔内容 | 预期揭示点 |
|---|---|---|
| F1 | …… | 第N场/某场景 |
```

`campaign/<模组id>/routes.md`：

- **主线序**：场景的理想推进顺序
- **关键节点**：错过即坏局的节点（预写稿据此选取）+ 每个节点的回拉手段（若玩家绕开，从哪里把线索再递一次）
- **可跳过项**：纯风味场景

**停下，请 KP 校对：直接修改生成文件后说"继续"。**

### 步骤 4：预写稿

`campaign/<模组id>/drafts/<场景id>.md`，依 routes.md 的关键节点选取：

- 每场景**开场白**一份（box_texts 原文 + 到场节拍连发，遵循 corpus/文风锚点.md 的节拍模式）
- 关键检定的**成败两版**描述（遵循 corpus/techniques/写作纪律.md 的检定分层描述法）

**停下，请 KP 校对：直接修改生成文件后说"继续"。**

## 铁律（不可违反）

1. 骰子和规则计算不交给 LLM——数值表不进上下文，只留 stats_ref
2. 走向决策归 KP——本 skill 只做素材加工，预写稿是备选不是剧本
3. 长团记忆外置——一切产物落盘为 markdown 文件
