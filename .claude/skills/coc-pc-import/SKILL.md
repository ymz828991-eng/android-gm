# coc-pc-import 玩家角色导入

让每个 PC 与这个故事产生**只属于他/她**的联结。理论依据：规则书 §10.3（撒饵，让玩家自己咬）与 §10.5（背景条目作为情节跳板与扭曲素材）。

## 流程

1. **读 PC 背景**：玩家提交的背景/人物卡；若只有口头描述，追问三件事——出身地与家族、与谁有羁绊、靠什么谋生
2. **对照连接点**（读 module.md 真相摘要 + 伏笔登记表 + 场景卡清单）：
   - **NPC 旧缘**：背景中的亲属/朋友/仇家，能否挂到模组 NPC 上（改 NPC 细节适配，优于新增 NPC——规则书 §10.3）
   - **姓氏与地域**：家族名/出身地与模组时代的联系（如德弗洛家的诺曼底产、莱维特祖缘）
   - **技能与职业**：谋生手段对应的独有线索通道（猎场看守惯查燃料源、海关官员熟走私门路）
   - **情感联结**：背景里的遗憾/执念，与模组主题（守护、贪婪、复仇、信仰）的共振点
   - **伏笔挂靠**：伏笔登记表中哪些 F# 由该 PC 揭示最有力（玛丽的十字架、伊丽莎白的神秘学）
3. **生成钩子**：每 PC 2-3 个，写入 `campaign/<模组id>/pcs/<PC中文名>.md`：

```markdown
# <PC 名>
## 背景（玩家提交原文 + 导入时补充）
## 一句话状态（开团时）
## 个人钩子
- **<类型>**：<钩子内容>（挂靠：<场景名> / <NPC名> / F#）
```

4. **场景挂注**：在相关场景卡的"## PC 挂注"节下追加一行：`<PC名>：<一句话——该场景对此PC的独特意义或提示>`
5. 呈 KP 审阅后落盘

## 钩子纪律

- 钩子是**叙事素材**不是机械加成——可以建议"此处可斟酌给奖励骰"，不得擅自发明规则
- 不改模组真相与关键节点；改的是 NPC 的可变细节（名字、年龄、次要关系）
- 每个钩子必须可追溯（挂到具体场景/NPC/伏笔编号），消费者和 KP 都能查到

## 铁律
1. 骰子和规则计算不交给 LLM
2. 走向决策归 KP——钩子是备选联结，KP 可删可改
3. 长团记忆外置——钩子落盘到 pcs/ 与场景挂注，不留在上下文
