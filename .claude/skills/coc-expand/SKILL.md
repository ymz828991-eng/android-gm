# coc-expand 模组拓展（探测＋按需生成）

对模组做体检：探测卡关风险、深挖潜力、手稿机会与结构节奏缺口，产出**清单**供 KP 按需点选；KP 点了才生成，KP 也可自己写。

## 核心原则

1. **探测只读模组原文**——`logs/extracted/_<模组名>_mod.txt` 是唯一事实源；module.md/场景卡等 prep 产物是失真的蒸馏物，只作定位索引，在蒸馏物上探测等于二次失真
2. **探测不产内容，生成不抢跑**——报告条目只写"发现＋潜在动作"，KP 未点选前不生成任何拓展内容
3. 跑团进行中不跑本 skill（模组库冻结，变化走 state）

## 两个入口

| 入口     | 触发                             | 原文来源                               |
| -------- | -------------------------------- | -------------------------------------- |
| 备团尾随 | coc-prep 步骤 5 调用（同上下文） | 已在上下文，直接探测                   |
| 补探测   | KP 对已备模组单独要求            | 重读原文全文（分段，同 prep 通读纪律） |

## 探测规则集（四类十六条）

### A 卡关风险（三线索原则）——最优先

| #  | 规则       | 探测什么                                                                                                          |
| -- | ---------- | ----------------------------------------------------------------------------------------------------------------- |
| A1 | 结论线索数 | 玩家必须抵达的每个结论（真相揭示＋主线任务自身的问题，如"死因是他杀"），在**原文**中数独立线索源，<3 条标红 |
| A2 | 卡点单解   | 关键节点只有一条解法，尤其只靠一次检定                                                                            |
| A3 | 僵局无后备 | 玩家卡住时没有可启动的积极主动事件（"带枪的家伙进门"/敌人下一步计划启动/某人死了）                                |
| A4 | 烟雾弹     | 模组故意误导处，标注"需配无可辩驳的事实"或建议削除——玩家自造怀疑已足够                                          |

### B 深挖潜力（编剧课堂）

| #  | 规则         | 探测什么                                                                                                      |
| -- | ------------ | ------------------------------------------------------------------------------------------------------------- |
| B1 | 欲望不原始   | NPC 动机是抽象词（职责/忠诚/贪婪）而非原始驱力（复仇/求生/占有/守护/被爱）——改写候选                        |
| B2 | 深挖潜力     | 跨场景出场但背景单薄的 NPC：改一两笔经历可成叙事主角/暗线。特别留意**原文中时间轴重合但未连线的线索束** |
| B3 | 障碍单一     | 关键对抗只有对手因素，缺环境/自造因素（障碍须组合式）                                                         |
| B4 | 悬念机制缺位 | 全程无时间锁/炸弹/假身份/环境类机制，张力平缓                                                                 |
| B5 | 配角功能重叠 | 职能重复、可合并的 NPC                                                                                        |

### C 手稿机会（争取打字时间）

| #  | 规则           | 探测什么                                                                                                                                                              |
| -- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| C1 | 口述信息密集点 | 大段背景/人物关系靠 KP 打字交代处——可预制高密度文档（遗书/日记/信件/报纸/收据/电报），一份好手稿能让 PL 自己讨论二十分钟                                            |
| C2 | 关系缠绕点     | 人物关系足够纠缠、适合 Who（谁写的）/How（怎么留下、怎么被找到）/What（什么载体）三问设计的文档点。好手稿含内在矛盾与可质疑的真实性（泥点、措辞破绽），可承载叙事诡计 |

### D 节奏与场景结构（节奏掌控＋场景物理逻辑）

| #  | 规则         | 探测什么                                                                                                                                                                                |
| -- | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1 | 问题类型混杂 | 一场戏叠加多类挑战——考语文时不考数学                                                                                                                                                  |
| D2 | 生死抉择裸奔 | 重大二选一/生死关口前没有铺垫场景，突然抛出会打懵玩家                                                                                                                                   |
| D3 | 场景纵轴化   | 描述停在标签层（"破败的码头"），缺横轴可演出细节。物理痕迹法候选：想放的信息会留下什么痕迹——打翻的罐子=有东西被匆匆拿走；关不上的歪抽屉=高频使用之物；一直抽风的通风橱=绝不能泄漏之物 |
| D4 | 神话生物超配 | 怪物/超自然出场密度过高——熟识生轻蔑，一闪而过比成群可怕；人类反派可更吓人                                                                                                             |
| D5 | save 点空白  | 多场次模组未标悬念收尾候选（死亡/重大发现/决战前）。单晚模组不适用，勿硬套                                                                                                              |

**不适用就不写**——报告的说服力靠每条都站得住，凑数条目会毁掉整份报告的可信度。

## expand.md 契约

```markdown
# <模组名> 拓展探测报告
## 元信息（探测日期；入口：备团尾随/补探测）
## A 卡关风险
### A1-1 <一句话发现>
- 位置：<场景卡/NPC 卡/原文场景页>
- 发现：<具体证据，引原文>
- 潜在动作：<可生成什么，一句话：补线/多解方案/后备事件/手稿/NPC 深化/场景细节>
- 状态：待定
（B/C/D 同构，各自 ## 一节）
## 已生成产物索引（阶段二追加）
| 条目 | 产物 | 位置 |
|---|---|---|
```

- 排序：A 全部在前，B/C/D 按潜力排
- 状态机：`待定 → 已生成 / KP自写 / 忽略`（KP 改状态即指令；"忽略"也保留条目备查）
- 条目编号 `<规则>-<序号>` 是稳定句柄，KP 用它点选（"生成 A1-1"）

## 按需生成（阶段二）

KP 点条目 → 只做该条 → 落点按性质分流，**给消费者读的进卡片，给 KP 参考的留报告**：

| 产物                        | 落点                                                                                          |
| --------------------------- | --------------------------------------------------------------------------------------------- |
| NPC 深化                    | 对应 NPC 卡尾部`## 拓展` 节                                                                 |
| 场景细节扩写/补线           | 对应场景卡尾部`## 拓展` 节                                                                  |
| 高密度手稿                  | `campaign/<模组>/handouts/<名>.md`（成品全文，可直接递出；KP 说明置于文件头，删除即可递出） |
| 多解方案/后备事件等策略内容 | expand.md 该条目下（KP 跑团时翻报告用）                                                       |

- 生成内容一律以 `## 拓展` 节或产物索引行标注来源，与模组原文永不相混；**场景卡的"场景原文/box_texts"节永不改动**
- 生成后更新条目状态＋产物索引
- 隔会话生成：读该条目涉及的原文段落＋相关卡片（局部定位即可，不需全文通读）
- 手稿类产物（handouts/）语言遵循 corpus/techniques/语域.md"书面手稿拟真"条目——真文档语言：名词+数量+真划掉，禁成句禁推理

## 边界

- 探测中发现 prep 产物本身的完整性问题（缺卡、引用悬空、摘要与原文不符）→ 报告里单列一节提醒 KP 回 coc-prep 补，本 skill 不代补
- 不写 runs/、timeline、state；模组库中只写 expand.md、卡片拓展节、handouts/
- 铁律：骰子计算不碰、走向决策归 KP、一切落盘
