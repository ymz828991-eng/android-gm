# 文风语域系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地文风语域系统——锚点重构（协议+画风系统+默认白描）、techniques 语域条目、低电 log 提取与语料库、consumer/expand skill 改动。

**Architecture:** 三轴模型（画风主轴×文本形态×风味标签，只索引不矩阵）。锚点瘦身保协议与默认档；techniques/语域.md 收全部语域条目（每条≤15行，三段式）；fragments 收逐字语料；低电 log 经脚本分离 KP 消息后分块蒸馏。

**Tech Stack:** 纯 markdown 产物 + python 标准库（zipfile/re 解 docx）。无测试框架，验证用脚本输出、grep、逐字比对、文本走查。

**Spec:** docs/superpowers/specs/2026-09-18-文风语域系统-design.md（本计划从 spec 出发，执行者两份都读）

## Global Constraints

- 全部产物中文；条目名精确拼写：`日常/白描`、`经典恐怖/悬疑`、`抒情/温情`、`NPC 对白声部`、`书面手稿拟真`、`现代媒介`；低电系画风条目名**由蒸馏结果定，不预设**
- 蒸馏只认三层：表达（语感/句长/语域色彩）、结构（信息次序/节拍组织/蒙太奇/并置）、修辞（比喻/反讽/留白）。表面机制（标点/字数习惯）是媒介纹理，只作备注永不立条目（记忆 style-distill-lens）
- 逐字样本不改写；低电样本可追溯（说话人+时间戳）
- 三轴只索引不组合矩阵；无血统系统；不建无源条目（东方/侦探/魔幻留空）
- 直接 commit 到 main（仓库惯例）；commit message 用仓库风格（`feat:`/`docs:` + 中文摘要）
- 本工程是 KP 委托语料建设，corpus 写入合法（spec §7）；首个 commit message 注明
- 工作文件（脚本/提取文本/蒸馏笔记）落 `docs/superpowers/working/` 并 commit（来源可追溯）
- docx 备选源：`ref/log区/低电log 染色版.docx`——仅当说话人标签分离不可靠时启用

- [ ] **Step 1: 写普查脚本**

`extract_kp.py` 全文：

```python
# extract_kp.py — 低电log.docx 说话人普查与 KP 消息分离
# 用法: python extract_kp.py census   # 普查，人工确认 KP 账号集
#       python extract_kp.py split    # 按 KP_SET 分离写 低电KP提取.txt
import zipfile, re, sys, io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')

DOCX = 'ref/log区/低电log.docx'
OUT  = 'docs/superpowers/working/低电KP提取.txt'
KP_SET = set()  # census 后填，预期含 洄音识路、萤石眼，以普查结果为准

z = zipfile.ZipFile(DOCX)
xml = z.read('word/document.xml').decode('utf-8')

# 段落级提取：每个 w:p 内的 w:t 连接为一段
paras = []
for p in re.findall(r'<w:p[ >].*?</w:p>', xml, re.S):
    t = ''.join(re.findall(r'<w:t[^>]*>([^<]*)</w:t>', p))
    if t.strip():
        paras.append(t)

hdr = re.compile(r'^【([^】]+)】\s*([^\s【]+)')

if sys.argv[1] == 'census':
    census = {}
    for t in paras:
        m = hdr.match(t)
        if m:
            k = f'{m.group(1)}|{m.group(2)}'
            census[k] = census.get(k, 0) + 1
    for k, v in sorted(census.items(), key=lambda x: -x[1]):
        print(v, k)
    print('total paras:', len(paras))
elif sys.argv[1] == 'split':
    assert KP_SET, '先跑 census 并填 KP_SET'
    out, keep = [], False
    for t in paras:
        m = hdr.match(t)
        if m:
            keep = m.group(2) in KP_SET
        if keep:
            out.append(t)
    with open(OUT, 'w', encoding='utf-8') as f:
        f.write('\n'.join(out))
    print('KP paras:', len(out), 'chars:', sum(map(len, out)))
```

文件全文如下（示例逐字取自现锚点，不得改写）：

```markdown
# 语域（画风 × 文本形态）

三轴模型的审美层条目：画风是主轴（决定表达/结构/修辞），文本形态与风味标签是辅轴。
默认画风=日常/白描；切换由 KP 点名。条目简短有力，随复盘持续打磨。
表面机制（标点/字数习惯）属媒介纹理，永不立条目。

## 画风

### 日常/白描（默认）
- **适用**：未点名画风的全部叙述——路程压缩、转场、日常应答、平事件推进
- **做法**：只给可感事实（物件/动作/声音/数字），动词优先，修饰从句能删则删；留白=句号提前，情绪不落地成词；平路段用过渡词直接略过
- **示例**：「你们一直往西走，路上没有人，也没有遇到什么猛兽，顶多有些鸽子乌鸦，飞来飞去。」
- **来源**：《不息的渴望》[1场·路程压缩]；《追书人》

### 经典恐怖/悬疑
- **适用**：怪物戏、揭示戏、侦查给线索——KP 点名或剧情自然进入时
- **做法**：少即是多，一场只给一个最异质细节；描述证据不点破因果；异常点收尾独条成拍；感官递进视觉→听觉→体感；重复场景锚定句不变+差异独条强调
- **示例**：「尽管风很大，但他的长袍似乎……纹丝不动？」
- **来源**：《不息的渴望》[2场/3场]；规则书 §10.15

### 抒情/温情
- **适用**：日后谈、落幕复位、告别——KP 点名"温情/煽情/抒情"时
- **做法**：色彩三阶渐变+声音接力；日常物件承载情绪（碗碟/腌菜罐/那沓钱）；收在日常动作上，不收在感悟上；一场至多一次
- **示例**：「天是从窗帘缝里一点一点亮起来的。先是灰，再是青，再是一种洗净了的白。」
- **来源**：《追书人》（天亮/日常复位）；文风锚点"升档标杆"

## 文本形态

### NPC 对白声部
- **适用**：任何 NPC 开口
- **做法**：身份语气定型（市井/古语/话痨/守墓人粗哑）；对白后缀一小动作；身体先于言语（欲言又止=铲子杵着人没动）；异类声部用异类逻辑（道格拉斯的"线头"论证）
- **示例**：「"……我还有活。"他说。可铲子杵在那儿，两只手搭在铲柄上，人没动。」
- **来源**：《不息的渴望》NPC 对白节；《追书人》杰弗逊/道格拉斯

### 书面手稿拟真
- **适用**：遗书/日记/信/报纸/收据/电报/备忘录/清单等 handout 文本
- **做法**：真文档语言——名词+数量+真名+真划掉；禁成句禁推理；情绪来自并置与物理痕迹（泥点/措辞破绽/（划掉）注记）；时代格式对表（电报计字、报纸排版）
- **示例**：「3/12 药 2瓶 / 给K君回信（未寄）」
- **来源**：爱憎之赘手稿实践（两轮校订定稿）；KP 纪律
```
