# 理想路线（routes）

## 主线序（事件时间轴，模组原文）
1. 调查员从敦威治南边树林开始每次循环。几分钟后塔昆自东向西飞过头顶
2. 除非被干涉，霍金斯杀死芬彻；芬彻鬼魂在圣巴塞罗缪教堂出现；霍金斯点燃磨坊
3. 远处磨坊燃烧。莱维特带莎拉到教堂控告女巫；同时霍金斯前往莎拉住所
4. 霍金斯点燃莎拉住所，更多卫兵上街；霍金斯返回莱维特宅邸
5. 莎拉的密友（三巫师）闯教堂寻人，遭遇鬼魂；骚乱引来沃尔特·卢卡斯敲钟
6. 牧师们正要烧死莎拉；钟声中莎拉向主人祈求，闪电照亮东海岸，她死于火刑，风暴潮席卷，时光圈重置

场景推进链：海岸走私 → 树林苏醒 →（林间空地 / 直奔磨坊）→ 磨坊 → 进城之路 → 港湾旅店 / 莎拉的住所 / 莱维特的宅邸 / 圣巴塞罗缪教堂 → 烧死莎拉 →〔重置回树林苏醒〕或〔救下 → 世界边缘 → 尾声〕

## 关键节点（错过即坏局 + 回拉手段）
| 节点 | 内容 | 错过后果 | 回拉手段 |
|---|---|---|---|
| N1 磨坊救芬彻 | 首圈内足够快抵达，拦下神父/堵门 | 教堂出现鬼魂，地穴与谈判线变难（可极难说服） | 下圈提前直奔磨坊（树林落地即走） |
| N2 教堂庭院救莎拉 | 火刑前到达并说服/武力介入 | 莎拉被烧死→轮回重置+全员衰老 | 三巫师提供"莎拉在教堂"情报；下圈再来 |
| N3 打破时光圈 | 钟不响（阻止沃尔特/毁钟）或在祷词前救下莎拉 | 无限循环直至属性归零 | 否认现实检定给暗示；三巫师借口的建议（"反复经历直到完成某种使命"） |
| N4 虚空穿越 | 需莎拉引路（或自力更生线：聆听定位） | 迷失虚空，化为虚无 | 绳索/布条绑手=自动连接（奖励机智） |

## 可跳过项
- 沃尔伯斯威克镇（无剧情，引导回城或直接重置）
- 莱维特宅邸（若霍金斯已在磨坊被擒并招供）
- 亨利·斯科特二遇（可选指示器）
- 监狱线（被动触发，轮回报废）

## 时光圈差异点（每圈可改变的分叉）
- **圈1**：只能目睹结果（磨坊已焚、神父已死、火刑进行时）——收集信息
- **圈2+**：可提前拦截——直奔磨坊救芬彻；住所堵霍金斯；林间说服三巫师同行；带神父去教堂谈判；阻止沃尔特敲钟
- 每圈玩家多知道一分：告知三巫师"莎拉被关教堂"会直接改变 N2 的兵力构成（三巫师强攻 vs 神父谈判 vs 独自说服，三条路线见 烧死莎拉 卡）
- 玩家拖延/跑偏 → KP 主动重置（module.md 时光圈法则第7条）
