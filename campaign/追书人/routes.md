# 追书人·路线

## 主线序

**日间箱庭期**（六向自由序，以金博尔宅为据点往返）：

1. **金博尔宅**——开场委托 + 书房搜查（日记 F3 是全场最强线索，值得先给）
2. 调查自由序：**公墓**（杰弗逊 F5 + 墓碑勘察 F8，调查期信息密度最高）→ **邻里走访** F4 / **图书馆** F6 / **报社** F7 / **警局** F9·F10（图书馆与报社二选一即覆盖历史目击线索）
3. 收束判断：线索足以指向"人影夜行于墓地与宅子之间" → **守夜**

**夜线汇合**：

4. **守夜** → 三分支：**月下会面**（喊名跟随，真相线）／ **击倒之后**（攻击线，恐怖高潮）／ 人影逃脱（平淡收束）
5. **尾声**（结算与保密抉择）

**理想最短线**：金博尔宅（日记）→ 公墓（墓碑足迹→陵墓）→ 当夜守夜 → 月下会面 → 尾声

## 关键节点（错过即坏局 + 回拉手段）

1. **书房日记（F3）**——通往隧道认知与守夜动机的钥匙。
   回拉：孤注一掷；或托马斯主动进屋询问"是否找到了他叔叔的日记？（'我知道它就在这间屋子里。'）"帮忙指出位置——模组内置回拉，勿吝使用。
2. **守夜触发（夜线入口）**——玩家若想不到蹲守，托马斯要求汇报进展并建议"监视屋子抓现行"——模组内置回拉。
3. **喊名分支（月下会面入口）**——只有喊出"道格拉斯·金博尔"，人影才会停顿并引路上墓碑；只追赶不动手同样能抵达。错过不坏局：攻击线仍经 击倒之后·认脸 通向真相。
4. **最后一晚时限（F12）**——今夜之后食尸鬼封闭出入口一去不返；拖延不减损结局（盗窃自然止息），但错过今夜即错过一切当面真相。可用杰弗逊的"最近深夜"与书房空档渐增等细节提示时间紧迫。
5. **墓碑足迹→陵墓隧道（F8）**——撞见真相的捷径，但**错过不坏局**：模组明示某些行动可不解决事件而直达结局，守夜线完整保留一切揭示途径。

## 可跳过项

- **邻里走访**——纯风味佐证（奥黛尔夫人），无独家线索
- **警局**——红鲱鱼与排除法；其"六七年前怪响"F10 与图书馆/报社的历史线索重叠
- **图书馆 / 报社**——互为冗余入口，走其一即可（守秘人笔记明示：图书馆未找到的可在报社补上）
