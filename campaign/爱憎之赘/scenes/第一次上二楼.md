# 第一次上二楼

## 浓缩摘要
楼梯即事件：上楼先闻尸臭，聆听/灵感二选一（敏捷生物逼近/恐怖的东西要来了）；仍上楼过侦查对抗瞳的潜行70偷袭（目击 SC0/1d6）。瞳：白袍长发、胶皮皮肤、四足蹄爪、呻吟哭泣声，突袭轮一回合三动。任一方血量过半/重伤 → 阳太参战挡攻击、轻柔丢人下楼（此前未发现真身者 SC1/1d5；被告知过 SC1/1d3）。全员下楼：阳太最后滑下道歉→饼干罐（妈妈生病前做的，已干瘪没法吃）"我都舍不得吃"→求二次上楼"我会拦住妈妈的……太久我会没力气的"。第二次上楼前阳太在楼梯拐角等候：阻拦瞳成黑色雕像（瞳毫无反抗如睡着），二楼限时开放。

## 场景原文
没有露出真容的小男孩让人心生好奇，又或者调查员接到了他请求治疗妈妈。无论如何，只要调查员尝试走上楼梯，都会触发以下剧情。在市川瞳袭击之前，阳太并不清楚妈妈会攻击上楼的人。
第一次上二楼：
上楼过程中会首先嗅到一股尸体的臭味，并且过聆听/灵感（2选1）
过了聆听会听到仿佛有什么敏捷的生物听到了你的到来，开始向这边行走。
过了灵感会觉察到，仿佛有什么恐怖的东西要过来了。
如果调查员仍然要上二楼，就需要过侦查对抗变为食尸鬼的市川瞳的潜行偷袭（市川瞳潜行70，目击后需要进行SC0/1d6）。
市川瞳：
你们看到眼前的人影……不，也许不应该称之为人影了。
她穿着白色的袍子，长发披散在地上，看不清她的脸，但是可以从裸露在外的皮肤上，发现她的皮肤已经异化成了类似胶皮一样的东西。四足着地，长着蹄子般的脚，原本应该是手掌的部分则是长着两只利爪。她发出了像是呻吟和哭泣的声音，以极快的速度向你们袭来。
（此时，进入市川瞳的突袭轮，市川瞳一回合三动）
突袭轮结束：
此时市川阳太会对你们大喊："对不起、我不知道……你们快下去吧，下去就没有事了！"
如果调查员继续战斗，阳太会有些慌张的看着你们，在市川瞳的血量亦或者调查员的血量降低到一半以下/重伤的时候，阳太都会参与战斗，挡住妈妈的攻击，并将你们丢下楼（对重伤和受伤的人，他的动作会很轻柔，并不造成任何损伤）。
此时，如果之前没有人发现市川阳太的真身，则所有人SC1/1D5，之前发现的人，没发现但是又被告知过的人，SC1/1D3。
全员下楼：
在所有人下楼后，阳太会最后一个下楼，小恐龙怯生生的滑下来，以他也不知道妈妈会这样为由对你们道歉。
接着，他的那张由黑色液体构成的脸上，露出了像是小狗一样讨好的表情，然后不知道从哪里摸出了一个饼干罐。这个饼干罐看上去有些旧了，其中一个角更是凹陷了下去，像是被什么人狠狠的摔过。
他拉住了你们的衣角，从里面掏出了几块饼干，试图递给你们。——那个表情，就像是在递给你们一把金子。
"那是妈妈生病之前做的，我……我都舍不得吃……"
你们可以看到，饼干不知道放了几个月，已经干瘪的没法吃了。
他会提出去拦住妈妈的提议，并且乞求你们再去一次二楼。
"我……我会拦住妈妈的。我可以抱住她……但是这样的话，不能太久，太久我会没力气的。而且对妈妈的身体也很不好……"
在你们第二次前往二楼之前，他会在楼梯的拐角等待你们。
可选描写——"那么你们又回到了客厅，阳太依然坐在楼梯上，他似乎已经非常习惯这样的姿势了，也许在母亲生病以后，他就经常这样默默地等着"
阳太阻拦瞳：
你们看到阳太走上了二楼，随后，从黑暗中，浮现出了市川瞳那可怖的形貌。但是她没有像攻击你们那样去袭击阳太，而是低头看着自己小小的孩子，随后……她迟疑的伸出爪子，摸了摸阳太的头。"妈妈，对不起，但是我想帮叔叔他们的忙。睡一会儿就好了。"阳太小声的说，然后，你们看可以看到黑色的液体从市川阳太的四肢蔓延出来，形成了一张黑色的幕布，将他和母亲包在了里面。
市川瞳没有任何反抗，抱住了阳太，也被阳太彻底包裹，形成了一尊黑色的雕像。
你们跑到了二楼，市川瞳没有对你们产生任何反应，就像阳太说的那样，她似乎只是睡着了。
二楼可以进入了。但是有时限。二楼部分见下文。

## 出入口
- 进入：`客厅与厨房` 上楼梯（好奇小男孩/医生线请求均可为动机）
- 出口：撤退回一楼 → 阳太阻拦 → 二楼四室限时开放：`卧室` / `儿童房` / `储物间与游戏房` / `浴室`
- 检定意图：聆听或灵感（二选一预警）；侦查 vs 潜行70（偷袭对抗）；SC 分级见上；战斗数值归 KP（瞳 stats_ref → npcs/市川瞳）
- 备注：阳太阻拦时限——"不能太久"（KP 把控二次探索的时间压力）
