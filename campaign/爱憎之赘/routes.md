# 理想路线（routes）

## 结构说明

一夜箱庭：模组作者的"简单流程梳理"是**理想序**而非硬轨——宅内探索顺序自由，事件由触发器驱动（见下表）。KP 的职责是盯触发器与线索余量，玩家绕路不坏局，漏关键线索才坏局。

## 主线序（作者理想流程 → 场景卡映射）

1. PC 接电话并在做出准备后到达 → `开场导入` → `屋外与庭院`
2. 阳太的出现（若全程无声可后移）→ `阳太出现`
3. 撒托古亚的降临（空间封锁开始）→ `撒托古亚的降临`
4. 一楼探索 → `客房`（大川手机）→ `客厅与厨房`
5. 第一次上二楼（瞳袭击）/地下室探索 → `第一次上二楼` / `书房`→`地下室`
6. 第二次上二楼（阳太阻拦瞳后限时）→ `卧室`/`儿童房`/`储物间与游戏房`/`浴室`
7. 书房计算机探索（密码来自二楼证件）→ `书房`
8. 线索收集完毕或 PC 陷入僵局 → 哲夫惨叫（通神术完毕+"祭品无法被复活"的答案）
9. 决战 → `决战` → `水泥房间` → `结局与后日谈`

自然动线依赖：二楼（密码/日记/病例）↔ 书房电脑 ↔ 地下室双书架 —— 三区互为钥匙，玩家任意顺序进入均能闭环。
